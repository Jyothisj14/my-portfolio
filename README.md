## Contact Form Delivery

The contact form submits messages in the background to Formspree (`https://formspree.io/f/mvkzqwop`) and displays an in-page success or error message without redirecting. Formspree must be configured to deliver submissions to `jyothisjayanna@gmail.com`.

The email icon and address in the contact section also open a message to `jyothisjayanna@gmail.com`.

## Getting Started

To run the portfolio locally:

```bash
git clone https://github.com/Jyothisj14/my-portfolio.git
cd my-portfolio
python -m http.server 8000
```

Then open http://localhost:8000 in your browser.
